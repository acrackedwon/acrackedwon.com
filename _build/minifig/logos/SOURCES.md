# Logo sources

Brand marks traced onto the Mercedes-style race suit by `../gen2026.py`. Trademarks of
their owners; used here only as fan-made decoration on the minifigure.

| file | mark | from (GitHub) |
|---|---|---|
| `amg.svg` | Mercedes-AMG wordmark | `simple-icons/simple-icons`, `icons/amg.svg` |
| `adidas.svg` | adidas performance mark | `simple-icons/simple-icons`, `icons/adidas.svg` |
| `snapdragon.svg` | Snapdragon mark (word set in Inter) | `simple-icons/simple-icons`, `icons/snapdragon.svg` |
| `gb-microsoft.svg` | Microsoft logo + wordmark | `gilbarbara/logos`, `logos/microsoft.svg` |
| `h-hpe.svg` | HPE logo | `homarr-labs/dashboard-icons`, `svg/hpe.svg` |
| `k-ineos.svg` | INEOS wordmark | `kevinrhaas/autoselector.polecat.live`, `assets/logos/ineos.svg` |
| `b-ubs.svg` | UBS keys + wordmark | `Bernice-Koh/pattern-mirror`, `frontend/src/assets/UBS_Logo.svg` |
| `d-crowdstrike.svg` | CrowdStrike falcon + wordmark | `detain/svg-logos`, `svg/c/crowdstrike-logo.svg` |
| `p-signify.svg` | signify wordmark (the `SVGID_1_` path) | `paug/android-makers-2020`, `images/logos/signify.svg` |
| `pw-1.svg` | PETRONAS, current emblem + wordmark (Wikimedia Commons `PETRONAS-logo.svg`) | `Shehroz616/rusa-memory-match`, `img/PETRONAS-logo.svg` |

The Mercedes star comes from the LDraw 2016 print (973pyl). OMP is set in Inter Bold.
